## 1. Постановка задачи

**Цель:** сравнить три подхода к прогнозированию временного ряда:
1. **Baseline** — «завтра = сегодня».
2. **MLP** — полносвязная нейросеть.
3. **LSTM** — рекуррентная сеть с памятью.

**Гипотеза (слайд 26):** «LSTM снижает ошибку относительно MLP и baseline на фиксированном TEST».

**Метрики:** MSE (Mean Squared Error), MAE (Mean Absolute Error).

---

## 2. Данные

**Источник:** Yahoo Finance (библиотека `yfinance`).
**Инструмент:** AAPL (Apple Inc.), дневные данные.
**Период:** 2018-01-02 — 2025-12-31 (2011 наблюдений).

**Предобработка (слайд 19, без data leakage):**
- Разбиение на train/test: **80/20** по времени (не перемешиваем).
- Нормализация: `mean` и `std` вычислены **только по train**.
- `scaled = (prices - mean_train) / std_train`.

**Окна (слайд 7):**
- Длина окна `WINDOW = 20` (20 предыдущих дней → 1 следующий).
- Train: 1592 окна.
- Test: 399 окон.

---

## 3. Архитектуры моделей

### MLP (слайд 8)

```
Linear(WINDOW → 64) → ReLU → Linear(64 → 1)
```

- Вход: вектор 20 значений.
- Выход: одно значение (прогноз цены).

### LSTM (слайд 13)

```
LSTM(input_size=1, hidden_size=32, batch_first=True) → Linear(32 → 1)
```

- Вход: последовательность `[batch, 20, 1]`.
- Выход: одно значение.

### Baseline (слайд 5)

```
P[t+1] = P[t]
```

Прогноз = последнее известное значение.

## 6. Интерпретация

### 6.1. Baseline — сильнейший конкурент

Baseline («завтра = сегодня») даёт **MSE = 0.0056** — это очень низкая ошибка. Причина: **цены акций близки к случайному блужданию**. Сегодняшняя цена — лучший предиктор завтрашней.

Это **ожидаемый результат** для финансовых рядов. Слайд 34 прямо предупреждает:
> «Красивый prediction может просто повторять вчерашнюю цену.»

### 6.2. MLP лучше LSTM на этом датасете

| Модель | Лучший MSE |
|---|---|
| MLP | 0.0070 |
| LSTM | 0.0262 |

**LSTM в 3.7 раза хуже MLP.** Причины:
1. **Мало данных** — 1592 окна недостаточно для LSTM с 32 скрытыми нейронами.
2. **Мало эпох** — 30 эпох недостаточно для рекуррентной сети.
3. **Переобучение** — LSTM склонна запоминать шум на малых данных.

### 6.3. Learning rate критически важен

| lr | MLP MSE | LSTM MSE |
|---|---|---|
| 0.0001 | 0.078 | 0.844 |
| 0.001 | 0.010 | 0.190 |
| **0.01** | **0.007** | **0.026** |

- **При lr=0.0001** — модели **недоучились** за 30 эпох.
- **При lr=0.01** — **лучший результат** для обеих архитектур.

**Вывод:** выбор learning rate даёт **11-кратное улучшение** MSE — важнее, чем выбор архитектуры.

## 9. Что можно улучшить (для будущих экспериментов)

1. **Прогнозировать доходности** `r_t = ln(P_t / P_{t-1})` вместо цен — доходности стационарны, baseline будет слабее.
2. **Больше эпох** — 100–200 для LSTM.
3. **Больше данных** — период 2010–2026.
4. **Другие признаки** — Volume, High-Low, RSI, MACD.
5. **Backtest с транзакционными издержками** — проверка прибыльности.

## 11. Второй эксперимент: прогноз доходностей

### 11.1. Постановка

**Проблема с первым экспериментом:** baseline «завтра = сегодня» оказался очень сильным на **ценах** — потому что цены нестационарны и сильно автокоррелированы.

**Решение:** прогнозировать **лог-доходности** вместо цен:

$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right)$$

**Почему это правильно:**
- Доходности **стационарны** — без тренда.
- Слабо автокоррелированы — baseline слабее.
- Это **стандарт** в финансовой аналитике.

### 11.2. Данные

- **Инструмент:** AAPL
- **Период:** 2018-01-02 — 2025-12-31
- **Доходностей:** 2010
- **Средняя доходность:** 0.000949
- **Стандартное отклонение:** 0.019371
- **Train:** 1592, **Test:** 398

### 11.3. Результаты

| Модель | lr | MSE | MAE |
|---|---|---|---|
| **Baseline** | — | **1.63348138** | **0.83309555** |
| MLP | 0.0001 | **0.88090783** | 0.61893374 |
| MLP | 0.001 | 0.91378355 | 0.64491129 |
| MLP | 0.01 | 1.05927944 | 0.72263747 |
| LSTM | 0.0001 | 0.86366940 | 0.60237741 |
| **LSTM** | **0.001** | **0.84137809** | **0.60400450** |
| LSTM | 0.01 | 0.88416332 | 0.61715347 |

### 11.4. Сравнение с baseline

| Модель | MSE vs baseline | Улучшение |
|---|---|---|
| **Best MLP** (lr=0.0001) | 0.881 vs 1.633 | **−46.1%** ✅ |
| **Best LSTM** (lr=0.001) | 0.841 vs 1.633 | **−48.5%** ✅ |

### 11.5. Интерпретация

**Baseline MSE = 1.633** — это **больше**, чем на ценах (0.0056), потому что доходности почти независимы друг от друга.

Если `r_t` и `r_{t+1}` независимы, baseline MSE ≈ 2 × var(r). После нормализации var(r) ≈ 1, значит baseline MSE ≈ 2 — что мы и наблюдаем (1.633).

**MLP и LSTM научились предсказывать доходности лучше baseline:**
- Они улавливают слабую временную структуру (автокорреляцию).
- Предсказывают значения ближе к среднему (≈ 0) — это снижает MSE.

**Сравнение MLP и LSTM:**
- **LSTM чуть лучше MLP** на доходностях — она видит временную структуру.
- Лучшая LSTM: **MSE = 0.841** (lr=0.001).
- Лучшая MLP: **MSE = 0.881** (lr=0.0001).

### 11.6. Learning rate

| lr | MLP MSE | LSTM MSE |
|---|---|---|
| 0.0001 | **0.881** ✅ | 0.864 |
| 0.001 | 0.914 | **0.841** ✅ |
| 0.01 | 1.059 | 0.884 |

**Для MLP лучше маленький lr**, **для LSTM — средний**. Это показывает, что оптимальный learning rate зависит от архитектуры.

### 11.7. Инженерный вывод

> **На фиксированном time split 80/20 прогноз доходностей AAPL показал:**
> - **MLP** улучшил baseline MSE на **46.1%** (0.881 vs 1.633).
> - **LSTM** улучшил baseline MSE на **48.5%** (0.841 vs 1.633).
> 
> **Это означает, что выбор целевой переменной критически важен:**
> - На **ценах** baseline побеждает — потому что цены сильно автокоррелированы.
> - На **доходностях** нейросети побеждают — потому что доходности слабо автокоррелированы, и модели улавливают временную структуру.
> 
> **Для практического применения** важнее прогнозировать доходности, а не цены — это стандарт в финансовой аналитике.

### 11.8. Ограничения

1. **Транзакционные издержки** не учтены.
2. **Backtest** не проводился — MSE ≠ прибыльность.
3. **Один инструмент** (AAPL) — результаты не обобщаются.
4. **Не проверены другие окна** (5, 10, 50).
5. **Не тестировались другие признаки** (объём, волатильность).
